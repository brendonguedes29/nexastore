# Nexa Gestão V25 — Ativação e gestão de colaboradores

- Exibe o e-mail cadastrado na lista e na edição do colaborador.
- Busca também por e-mail.
- Adiciona ação de reenviar ativação para contas ainda não ativadas.
- O sistema deixa de afirmar que o e-mail foi enviado quando o serviço de e-mail lança erro; mostra aviso e permite nova tentativa.
- Aprovação de cadastro reutiliza o mesmo fluxo central de envio de ativação.
- Adiciona exclusão explícita de colaborador com confirmação, mantendo desativar/reativar como alternativa.
- Não altera modelos nem cria migration.
