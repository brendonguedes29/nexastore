# Nexa Gestão V16 — Fluxos, conteúdo e UX

Principais ajustes desta versão:
- Workspace/Notas do gestor e colaborador unificados visualmente, com seletor de cor, início, previsão, status e conclusão automática.
- Alertas de prazo também para notas; concluído fica verde e vencido fica vermelho na interface.
- Planos das ferramentas passam a exibir controle explícito de início, previsão, status e conclusão real.
- Alterar um plano atualiza o mesmo registro; novo registro só é criado ao criar uma nova análise/plano.
- Etapas metodológicas guiadas continuam específicas por ferramenta e ligadas ao plano.
- Treinamentos Nexa ganharam conteúdo didático substancial por etapa e visual de etapas clicáveis/expansíveis.
- Landing page reorganizada e menu comercial refinado.
- Login ganhou Voltar para o site e Criar conta da empresa.
- Cadastro empresarial refinado com validação de telefone com DDD.
- E-mail de ativação deixa preço fora da confirmação de conta; informação comercial permanece no fluxo de contratação.

Validação local do pacote: arquivos Python compilados com `py_compile`. Execute `python manage.py check` no Codespaces antes do commit e deixe o Render executar `migrate` no build após o push.
